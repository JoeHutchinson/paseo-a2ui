# Security policy

This plugin's daemon-side code runs unsandboxed on the Paseo daemon host, and its client code runs inside the Paseo app, so security reports are welcome.

## Reporting a vulnerability

Report privately through [GitHub's private vulnerability reporting](https://github.com/JoeHutchinson/paseo-a2ui/security/advisories/new). Please do not open a public issue.

Include what is affected, steps to reproduce (for example an A2UI message that triggers the problem), and the Paseo version and platform.

## Supported versions

Only the latest commit on `main` is supported.
